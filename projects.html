Federated Learning for Adaptive Road Efficiency (FLARE)

Traffic lights that aren't coordinated across a city cause delays. FLARE proposes a decentralized network of IoT devices running a federated learning framework. The devices work in a secure, self-contained network, talking only to each other and the learning algorithm, and adjust signals using real-time traffic data and inflow-outflow equations.

I built a simulation of downtown Victoria in SUMO, explored peer-to-peer network designs in OMNeT++, and documented the work in bi-weekly updates.
